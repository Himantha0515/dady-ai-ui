# Dady.ai UI

Interactive React implementation of the **Dady.ai Mockups** design canvas (dark-mode AI creation platform).

Design source: `UI mockups needed/Dady.ai Mockups.dc.html` (Claude Design export).

## Run

```bash
npm install
npm run dev
```

## Screens implemented

| Route | Mockup | Notes |
|-------|--------|-------|
| `/` | 1d + 1f | Landing hero (split workspace) + sections |
| `/app` | 1h + 1c | Dashboard with labelled sidebar |
| `/app/create/image` | 1j | Image Generation Studio |
| `/app/video` | 1l | Video Studio + 80-credit confirm modal |
| `/app/models` | 1m | Models explorer + compare drawer |
| `/pricing` | 1n | Four-plan pricing |
| `/app/credits` | 1p | Credit wallet & usage |
| `/checkout` | 1q | UPI-first checkout + success |
| `/auth` | 1r | Sign-up / OTP states |

Visual system: Plus Jakarta Sans, `#08090D` canvas, `#7C5CFF → #3B82F6` primary gradient, status colors from the foundations sheet (1a).
